section01

環境構築・最小アプリ

▶アニメーションで確かめるリクエストからレスポンスまでURL を入力 → GET リクエスト → @app.route のすぐ下の関数が実行される → レスポンスが返り、ブラウザが画面を描く開く →

学習したこと

  • URL を入力して Enter を押すと、リクエストがサーバーへ送られる。表示される画面は、返ってきたレスポンス(HTML の文字)をブラウザが描いたもの
  • URL は「プロトコル・IP アドレス・ポート番号・パス」でできている
  • Flask は Web アプリを作るためのフレームワーク
  • @app.route("/パス") で、パスとすぐ下の関数を結びつける(ルーティング)

URL の読み方

最小アプリ(app.py)

# Flask を使えるようにする(flask ライブラリから Flask を読み込む)
from flask import Flask

# アプリを作る。この app が Web アプリ本体
app = Flask(__name__)

# @app.route("/パス"):URL のパスと、すぐ下の関数を結びつける(ルーティング)
# 127.0.0.1:5000/ が開かれたら、すぐ下の index() が実行される
@app.route("/")
def index():
    # return した文字が、そのままレスポンスになる(画面に表示される)
    return "Hello, Flask!"

# 127.0.0.1:5000/about が開かれたら、すぐ下の about() が実行される
@app.route("/about")
def about():
    return "このサイトについて"

# python app.py で実行したときに、サーバーを起動する
# debug=True:保存すると自動で再起動し、エラーの詳しい内容も表示される
# サーバーを止めるときは、ターミナルで Ctrl + C
if __name__ == "__main__":
    app.run(debug=True)

# から行の終わりまではコメント(説明のメモ)。実行には影響しない。

テンプレート・リンク

▶アニメーションで確かめるリクエストからレスポンスまで(リンク・404)リンクのクリックも GET リクエスト → render_template が templates から HTML を読む → 合う @app.route がないと 404開く →

学習したこと

  • HTML は templates フォルダに置き、render_template("ファイル名") で返す
  • templates フォルダは app.py と同じフォルダの中に置く
  • <a href="/about"> のリンクをクリックすると、URL を入力したときと同じく GET /about のリクエストが送られる
  • href のパスと @app.route のパスがそろっていないと 404 Not Found になる

app.py

from flask import Flask, render_template

app = Flask(__name__)

@app.route("/")
def index():
    return render_template("index.html")

@app.route("/about")
def about():
    return render_template("about.html")

if __name__ == "__main__":
    app.run(debug=True)

section03

値の受け渡し・for・if

▶アニメーションで確かめる値をテンプレートに渡す・for・ifrender_template で値を渡す → {% for i in range(count) %} で i が 0〜3 と変わる → {% if %} で表示が分かれる → できた HTML がレスポンスで届く開く →

学習したこと

  • render_template("a.html", 名前=値) で値を渡し、テンプレートの {{ 名前 }} で表示する。= の左がテンプレートで使う名前、右が Python の変数
  • {% for %} 〜 {% endfor %} で、リストの要素を1つずつ表示する(範囲は字下げではなく endfor まで)
  • 複数のリストを同じ番号でそろえ、{% for i in range(count) %} の i で取り出す
  • {% if %}・{% elif %}・{% else %} で表示を分ける
  • 合計や件数などの集計は、Python 側で for と if を使って計算し、結果だけを渡す
  • {{ }} や {% %} はサーバーの中で値に置き換わる。ブラウザに届く HTML には残らない

app.py(値を渡す)

names = ["ボールペン", "ノート", "消しゴム", "付箋"]
prices = [120, 200, 80, 150]
stocks = [40, 0, 25, 0]

@app.route("/items")
def items():
    count = len(names)
    return render_template("items.html",
        names=names, prices=prices,
        stocks=stocks, count=count)

items.html(for・if)

{% for i in range(count) %}
<tr>
  <td>{{ names[i] }}</td>
  <td>{{ prices[i] }}円</td>
  <td>
  {% if stocks[i] == 0 %}
    売り切れ
  {% else %}
    {{ stocks[i] }}個
  {% endif %}
  </td>
</tr>
{% endfor %}

テンプレートの書き方

書き方意味
{{ 名前 }}渡された値を表示する({{ i + 1 }} のように計算もできる)
{% for x in リスト %} 〜 {% endfor %}1つずつ取り出してくり返す
{% for i in range(count) %}i が 0, 1, 2 … と変わりながらくり返す
{% if 条件 %} 〜 {% elif %} 〜 {% else %} 〜 {% endif %}条件で表示を分ける
len(リスト)リストの要素の数(Python 側)
リスト.append(値)リストの後ろに値を追加する(Python 側)

section04

フォーム

▶アニメーションで確かめるフォームの値が届くまでname=値 → POST /confirm → request.form で受け取る → int() → 計算 → {{ }} に値が入る → 確認画面開く →

学習したこと

  • <form action="/confirm" method="post"> で、送信先のパスと送り方を決める
  • 入力欄の name が、Python で取り出すときの名前になる(request.form["name の値"])
  • POST を受け付ける関数には methods=["POST"] を書く(書かないと 405)
  • フォームの値はすべて文字列で届く。計算に使うときは int() で整数にする
  • ドロップダウンリスト・ラジオボタンは、選んだ value が1つ届く
  • チェックボックスは選んだものだけが届き、request.form.getlist("名前") でリストとして受け取る
  • GET は値が URL に付く。POST は値がリクエストの本文で送られる(暗号化は HTTPS の役割)

送る側(order.html)

<form action="/confirm" method="post">
  <input type="text" name="customer" required>
  <select name="item">
    <option value="0">ボールペン</option> …
  </select>
  <input type="number" name="qty" min="1" required>
  <input type="radio" name="delivery" value="0" checked>
  <input type="checkbox" name="option" value="0">
  <button type="submit">確認画面へ</button>
</form>

受け取る側(app.py)

@app.route("/confirm", methods=["POST"])
def confirm():
